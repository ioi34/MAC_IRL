# acmart 템플릿이 실제로 요구하는 것 (조사 결과)

조사 대상: `acmart-primary/` 의 `README`, `acmart.pdf`(User's Guide, 79쪽),
`acmart.dtx`, `samples/`(15개 예제 문서), `Makefile`.

## 결론부터

**acmart 템플릿에는 "논문의 장 구성"에 대한 규정이 없습니다.**

`samples/` 안의 예제 문서들이 `\section{Introduction}`, `\section{Template
Overview}`, `\section{Typefaces}`, `\section{Research Methods}` 같은 절을 갖고
있어서 목차 템플릿처럼 보이지만, 이것들은 **LaTeX 기능을 시연하기 위한 예제
문서 자신의 절**이지 논문 구성 지침이 아닙니다. `\section{Typefaces}`가 논문에
들어가야 할 리 없습니다.

**쪽수 제한도 템플릿에 없습니다.** 8쪽 제한은 ICAIF의 CFP(Call for Papers)에서
오는 것이며, 저장소 안에 CFP 문서가 없어 확인하지 못했습니다. 제출 전 CFP에서
(a) 본문 8쪽에 참고문헌이 포함되는지, (b) 부록이 쪽수에 포함되는지 두 가지를
확인해야 합니다. 다수의 ACM 학회는 참고문헌을 쪽수에서 제외하지만 ICAIF는
확인이 필요합니다.

## 템플릿이 실제로 강제하는 것 (지키지 않으면 오류 또는 반려)

| 항목 | 요구사항 | 현재 상태 |
|---|---|---|
| 문서클래스 | `\documentclass[sigconf]{acmart}` — ICAIF는 sigconf | `[sigconf,nonacm]` 사용 중. **제출 시 `nonacm` 제거 필요** |
| abstract 위치 | `abstract` 환경은 반드시 `\maketitle` **앞**에 와야 함. 뒤에 두면 컴파일 오류 | 기존 `paper-ko.tex` 준수 |
| CCS 개념 | `CCSXML` 환경 + `\ccsdesc` 둘 다 필요. https://dl.acm.org/ccs.cfm 에서 생성 | 기존 원고에 있음 |
| 키워드 | `\keywords{...}`, 쉼표 구분 | 있음 |
| **이미지 설명** | `\Description{...}`를 **모든** `figure`/`teaserfigure`/`marginfigure` 안에 넣어야 함. 시각장애 독자용 대체 텍스트 | 새 절의 그림 10개 모두 포함 완료 |
| 참고문헌 | `\bibliographystyle{ACM-Reference-Format}` | 준수 |
| 저자 정보 | `\author` + 구조화된 `\affiliation{\institution{} \city{} \country{}}` | 준수 (실제 정보로 교체 필요) |
| 익명 심사 | 익명 제출이면 `\documentclass[sigconf,anonymous]{acmart}` | **CFP 확인 필요** |
| 부록 | `\appendix` 이후에 배치. 참고문헌 앞/뒤 위치는 CFP를 따름 | 적용 완료 |

## 템플릿이 권장하는 것

- **표는 booktabs 사용** (`\toprule`, `\midrule`, `\bottomrule`). 세로줄 금지.
- **양단 컬럼 폭을 넘는 그림/표는 `figure*`/`table*`** 를 쓰고 페이지 상단에 배치.
- `teaserfigure` 환경: 저자 정보 다음, 본문 앞에 오는 대형 도입 그림.
  `\maketitle` **앞**에 두어야 함. (8쪽 제한에서는 사치일 수 있음)
- 수식 번호는 참조되는 것만 부여.
- `\balance`(마지막 쪽 컬럼 균형)는 acmart가 자동 처리.

## 우리 원고에 대한 실행 항목

1. 제출본에서 `nonacm` 옵션 제거, CFP에 따라 `anonymous` 추가 여부 결정.
2. CFP에서 쪽수 산정 규칙(참고문헌/부록 포함 여부) 확인.
3. `\Description` 누락 없는지 최종 확인 — 현재 10개 그림 모두 포함.
4. 저자/소속/이메일을 실제 정보로 교체(또는 익명 처리).

## 새 폴더 구조

원본 `acmart-primary/`는 템플릿 배포 파일만 남기고 복원했습니다. 논문 작업물은
모두 `paper-icaif26/`로 옮겼습니다.

```
MAC_IRL/
├── acmart-primary/          # ACM 배포 원본만 (클래스, bst, 문서, samples)
└── paper-icaif26/           # 논문 제작 폴더 (신규)
    ├── 00_템플릿_요구사항_정리.md
    ├── paper-ko.tex         # 기존 원고 (이동)
    ├── paper-ko.bib         # 기존 참고문헌 (이동)
    ├── paper-ko.pdf         # 기존 출력 (이동)
    ├── paper-ko-editable.pages
    ├── paper-refs-additional.bib
    ├── sections/            # 장별 원고
    ├── figures/             # 논문용 그림
    └── build/               # 컴파일 산출물 (_texaux/ 는 삭제해도 무방)
```
