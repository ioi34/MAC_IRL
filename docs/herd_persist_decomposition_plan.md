# herd 명세 결정 — persist 1순위 + Sias 분해의 실현 조건

> `herd_sias2002_analysis.md`의 후속. "persist + herd로 Sias 분해를 재현할 수 있는가"라는
> 제안을 검토하고, 대안(max 변형)을 실측으로 기각한 뒤, 실현에 필요한 데이터를 특정한 기록.
> 결론: **본 모델은 persist 단독(1순위), 유형 내 herding은 기관 세부 데이터로 별도 분석.**

---

## 1. 제안 — persist + herd = 유형 수준의 Sias 분해

Sias(2002)의 분해를 그룹 구성원 $N$명으로 일반화하면

$$\mathrm{Cov}(\Delta_t, \Delta_{t-1}) = \frac{1}{N^2}\Big[\sum_n \mathrm{Cov}(D_{n,t}, D_{n,t-1}) + \sum_{n\neq m}\mathrm{Cov}(D_{n,t}, D_{m,t-1})\Big]$$

앞 항이 **자기 과거를 따르는 성분**, 뒤 항이 **서로를 따르는 성분(herding)** 이다.

여기에 $N=3$(외국인·기관·개인)을 넣으면 두 성분이 우리 특징과 정확히 대응한다.

| Sias 성분 | 우리 특징 |
| --- | --- |
| 자기 과거를 따름 $\mathrm{Cov}(u_{i,t}, u_{i,t-1})$ | **persist** $= u_{i,t-1}$ |
| 서로를 따름 $\mathrm{Cov}(u_{i,t}, u_{j,t-1}),\ i \neq j$ | **herd** $= \tfrac{1}{2}\sum_{j\neq i} u_{j,t-1}$ |

**⇒ 제안은 수식적으로 정확하다.** persist와 herd를 함께 넣는 것이 곧 유형 수준의 Sias
분해이며, 현재 모델은 교차 성분(herd)만 갖고 자기 성분(persist)을 빼놓은 상태다.

---

## 2. 왜 우리 데이터에서 막히는가 — 시장청산

### 막는 조건 (정확한 형태)

$$\sum_{j \in \text{그룹}} u_j = 0 \;\Longrightarrow\; \text{herd}_i = \frac{-u_i}{N-1} \;\Longrightarrow\; \mathrm{corr}(\text{herd}_i,\ \text{persist}_i) = -1$$

**핵심: 이 결과는 $N$과 무관하다.** 구성원이 894명이어도 합이 0이면 상관은 여전히 −1이다.
따라서 조건은 "구성원 수"가 아니라 다음 하나다.

> **그룹이 시장을 소진하지 않아야 한다** (= 그룹 밖에 거래 상대가 존재해야 한다)

### 우리와 Sias의 구조적 차이

| | Sias(2002) | 우리 |
| --- | --- | --- |
| 그룹 | 기관 894개 | 유형 3개 |
| 그룹 밖 상대 | 개인·마켓메이커·비13F **존재** | 사실상 **없음**(세 유형이 시장 소진) |
| $\sum u$ | 0이 아님, 자유롭게 변동 | $\approx 0$ 강제 |
| 두 성분 | **독립적으로 식별** | 기계적으로 결합 |

실측: $\sum u$ 평균절대값 0.0133 vs $|u_{\text{foreign}}|$ 평균 0.1254 → 잔차는 스케일의 약 10%.
corr(herd, persist) = **−0.989 / −0.974 / −0.992**.

## 3. 검토한 우회 시도 — 모두 기각

### 시도 A. 분모 변경 (공통 분모 → 자기 분모)

현재 herd는 $u = \text{순매수}/\text{종목 전체 거래대금}$(공통 분모)을 쓰는데,
행동(action) 정의는 $u = (\text{매수}-\text{매도})/(\text{매수}+\text{매도})$(자기 분모)다.
분모가 유형별로 다르면 합이 0으로 강제되지 않는다.

| 정의 | $\sum u$ 평균절대값 | corr(herd, persist) 외국인/기관/개인 |
| --- | ---: | --- |
| 공통 분모 (현재 herd) | 0.0133 | −0.989 / −0.974 / −0.992 |
| 자기 분모 (action 정의) | 0.1134 | −0.860 / −0.732 / −0.895 |

**판정: 완화되나 불충분.** 개인은 VIF 5를 넘고, 기계적 연결이 남아 herding 계수의 경제적
해석이 여전히 오염된다.

> ⚠ **부수 발견 (별도 사안):** 현재 코드가 herd 특징과 행동(action)에 **서로 다른 $u$
> 정의**를 사용 중이다. 공선성과 무관하게 정합성 문제로 점검 필요.
> (`src/data/preprocess.py:53` vs `src/data/labels.py`)

### 시도 B. max 변형 (herd를 합/평균 대신 max로)

비선형이라 선형 항등식을 부분적으로 깬다. 실측:

| 주체 | mean(현재) | **max** | \|·\|최대 |
| --- | ---: | ---: | ---: |
| 외국인 | −0.989 | **−0.681** | −0.899 |
| 기관 | −0.974 | **−0.429** | −0.747 |
| 개인 | −0.992 | **−0.833** | −0.909 |

**기술적으로는 효과가 있다.** 그러나 세 가지 문제로 기각한다.

**① max는 "영향이 큰 쪽"이 아니라 "더 매수한 쪽"을 고른다.**
둘 다 순매도인 날: $u_j=-0.30,\ u_k=-0.05 \Rightarrow \max=-0.05$.
영향이 큰 대량 매도를 버리고 약한 쪽을 택한다 — 의도와 반대이며, 매수일엔 강한 쪽,
매도일엔 약한 쪽을 고르는 **방향 비대칭**이 생긴다.
의도에 맞는 `|·|최대`는 −0.899/−0.747/−0.909로 **개선이 거의 없다.**
→ **효과가 큰 버전은 의도와 다르고, 의도에 맞는 버전은 효과가 없다.**

**② 개선의 출처가 정보 손실이다.**
$\sum u \approx 0$은 **합**을 제약한다. max는 합의 함수가 아니라 "그 합이 둘 사이에 어떻게
쪼개졌나"에 반응해 제약을 벗어난다. 즉 상관 감소는 더 의미 있는 측정에서 오는 것이 아니라
**상태의존적 정보 폐기**에서 온다.

**③ 문헌 근거가 없고, 데이터 마이닝 우려에 저촉된다.**
LSV·Sias 어디에도 "상대 중 max를 따른다"는 측정은 없다(모두 집계 방향).
채택 근거가 "상관이 낮아져서"라면, 직교화를 기각한 것과 같은 기준에서 함께 기각해야
일관된다.

> **기록 가치:** 이 실험은 논문 각주·부록 재료가 된다 — "비선형 변형으로 항등식을 부분적으로
> 깰 수는 있으나(−0.99 → −0.43~−0.83) 그 이득이 정보 손실에서 오고 이론적 근거가 없어
> 채택하지 않았다"는 서술은 대안 검토의 증거가 된다.

### 참고: 직교화도 같은 이유로 기각

persist ↔ momentum 상관은 +0.432/+0.057/−0.412, VIF는 1.37/1.05/1.45로 **문제 수준이
아니다.** momentum에 직교화하면 상관을 0으로 만들 수 있으나, 이론에서 도출된 특징을
숫자로 검증하는 연구 취지상 **결과에 맞춰 변수를 손보는 것으로 비칠 수 있어** 채택하지
않는다.

## 4. 결정 — persist 1순위

**본 모델은 persist 단독을 사용한다.**

- Sias 분해의 **자기추종 성분**에 해당하는 측정 가능한 양
- 직접 관측량이며 해석이 모호하지 않음("어제 산 만큼 오늘도 산다")
- herd는 자기시차의 부호 반전(−0.99)인데 "남을 따른다"로 읽혀 오독 위험이 큼
- momentum과의 공선성 문제 없음(VIF 1.05~1.45)

### 반드시 명시할 한계

합산 flow의 지속성은 "같은 주체가 계속 사는 것"과 "다른 주체들이 이어받는 것"을 구분하지
못한다. Sias가 분해로 갈라낸 두 성분이 우리에겐 뭉쳐 있다.
따라서 **"herding"이라 명명하지 않고 `flow persistence`로 부른다.**

### 논문 서술 초안

> "Sias(2002)는 시차 상관을 자기추종과 상호추종으로 분해한다. 이 분해는 그룹 구성원이
> 시장을 소진하지 않을 때 성립한다. 세 유형이 시장을 거의 소진하는 유형 수준 데이터에서는
> $\sum_j u_j \approx 0$이 두 성분을 기계적으로 결합시켜(상관 −0.99) 분해가 불가능하다.
> 따라서 우리는 자기추종 성분(flow persistence)만을 측정 가능한 양으로 사용하고 유형 내
> herding은 주장하지 않는다."

이는 실패가 아니라 **"집계 유형 데이터에서 herding 분해가 왜 불가능한지"를 밝힌 방법론적
발견**이며, 이론 기반 특징을 숫자로 검증한다는 연구 취지와 정합한다.

## 5. 문헌대로 herding을 하려면 — 필요한 데이터

**수식적으로 불가능한 것이 아니라 데이터 문제다.** 필요한 조건은 §2에서 특정했다:
**그룹이 시장을 소진하지 않을 것.**

### 해결책: KRX 기관 세부 유형 (공개 데이터)

KRX 투자자별 매매동향은 기관을 **7개 세부 유형**으로 제공한다 —
금융투자·보험·투신·사모·은행·기타금융·연기금등.

$$\sum_{k \in \text{기관 세부}} u_k = u_{\text{기관계}} \;\neq\; 0$$

**세부 유형들의 합이 0이 아니다**(상대편에 외국인·개인이 있으므로). 정확히 Sias의 구조다.

- persist$_k$ = 그 세부유형의 전일 flow
- herd$_k$ = 나머지 6개 세부유형의 전일 flow 평균
- **두 성분이 기계적으로 묶이지 않아 분리 추정 가능**

→ **기관 내부의 진짜 herding**(예: 연기금이 투신을 따르는가)을 Sias 방식으로 측정 가능.

### 안 되는 것

| 시도 | 가능? | 이유 |
| --- | --- | --- |
| 종목 수 확대(다종목) | **불가** | 항등식이 **종목별로** 성립. 100종목을 모아도 각 종목 안에서 −1 |
| 외국인 내부 herding | 사실상 불가 | KRX는 "외국인/기타외국인" 2개뿐 → 짝 비교 수준 |
| 개인 내부 herding | 불가 | 세분화 없음(단일) |
| 개별 투자자 단위 데이터 | 불가 | 국내 일별 데이터로 미공개(13F 상당물 없음) |

### ⇒ 결론: 문헌 방식의 유형 내 herding은 **기관만 가능**

| 유형 | KRX 세분화 | 유형 내 herding |
| --- | --- | --- |
| **기관** | 7개 | **가능** |
| 외국인 | 2개(외국인/기타외국인) | 사실상 불가 |
| 개인 | 단일 | 불가 |

## 6. 함의 — 대칭성과 기회

### 함의 1. 대칭성이 깨진다 → 별도 절로

본 논문의 셀링포인트는 "세 유형을 동일한 틀로 대칭 추정"이다. herding을 기관에서만
측정하면 그 대칭이 무너진다. 따라서 **본 모델에 넣지 않고 별도 진단 분석으로 배치**한다.

### 함의 2. 하필 기관이라 오히려 값진다

- Sias 논문 자체가 **기관 herding**을 다룬다 → 문헌 정합성 최상
- 우리가 설명하지 못한 유일한 주체가 **기관**이다
- 기관 null의 유력한 원인으로 **세부 유형 간 상쇄**를 계속 의심해 왔다

이 확장은 두 가지를 동시에 겨냥한다.

1. **문헌 정합적인 유형 내 herding 측정**(분해 가능)
2. **기관 null의 원인 규명** — 세부 유형별로는 일관된 선호가 나오는데 합산에서 상쇄되는지

이는 "3-에이전트 틀을 깨는 것"이 아니라, **본 모델은 3유형 대칭 유지 + 기관 null을
진단하는 별도 분석**이다.

## 7. 정리

| 항목 | 결론 |
| --- | --- |
| persist + herd = Sias 분해? | ✅ **수식적으로 정확한 대응** |
| 우리 데이터로 가능? | ❌ 시장청산으로 두 성분이 기계적 결합(−0.99) |
| 수식적으로 불가능한가? | **아니오** — 데이터 구조 문제 |
| 막는 조건 | 그룹이 시장을 소진 → $\sum u = 0$ ($N$과 무관) |
| 분모 변경으로 해결? | 완화(−0.99→−0.73~−0.90)되나 불충분 |
| max 변형으로 해결? | 효과 있으나 의도 불일치·정보 손실·근거 부재로 기각 |
| 직교화? | 공선성 문제 없고(VIF<1.5), 데이터 마이닝 우려로 기각 |
| **본 모델 결정** | **persist 단독** ("herding"으로 명명 금지, 한계 명시) |
| 문헌 방식 herding | **기관 세부 7유형 데이터로만 가능** (KRX 공개, 수집 필요) |
| 다종목 확대로 해결? | ❌ 항등식이 종목별로 성립 |
| 기관 세부 분석의 위치 | 본 모델 밖 **별도 진단 절** (대칭성 유지 + 기관 null 규명) |
