# 컨텍스트 주효과(α) — 도입 계기와 Q&A 정리

> 컨텍스트 주효과 항 $\alpha^\top C$를 왜 추가하게 되었는지, 그리고 그에 대해 제기된
> 네 가지 질문과 답을 순서대로 정리. 논문 §3·§4.5 서술의 근거 자료.

---

## 0. 이 항을 추가하게 된 계기

### 0.1 출발점 — 컨텍스트가 예측을 개선하지 못했다

원래 모델의 컨텍스트는 **상호작용 형태**뿐이었다.

$$g_{i,t} = w_i(C_t)^\top \phi_{i,t}, \qquad w_i(C_t) = \beta_i + \mathbf{B}_i C_t$$

즉 컨텍스트는 특징의 **가중치를 국면에 따라 조절**하는 역할만 했다. 그런데 실험
(2026-07-19, 3특징)에서 **컨텍스트를 넣어도 표본외 성능이 개선되지 않았고, 오히려
소폭 하락**했다. 컨텍스트를 아예 뺀 모델이 가장 좋았다.

### 0.2 원인 진단 — 구조적으로 담을 수 없는 정보가 있었다

진단 결과 1순위 원인은 **컨텍스트 주효과의 부재**였다.

정책이 $g=(\beta+\mathbf{B}C)^\top\phi$ 형태이므로, 컨텍스트는 특징 민감도만
조절할 수 있고 **행동의 수준(level) 자체를 움직이지 못한다.** 그런데 데이터에서는
컨텍스트가 행동과 **직접** 상관을 가지고 있었다:

| 컨텍스트 | 외국인 flow와의 상관 |
| --- | ---: |
| kospi_return_1d | **+0.174** |
| fx_level_z_252 | **−0.183** |
| vkospi | −0.141 |

"시장이 오르는 날 외국인은 (개별 특징과 무관하게) 그냥 더 산다"는 **수준 신호**가
실재하는데, 기존 구조는 이를 담을 그릇이 없었다.

부차적 원인들: 컨텍스트–특징 중복(kospi↔momentum +0.216, underwater −0.285),
상호작용의 2차적 기여와 낮은 부호 일관성, 지속성 높은 국면변수(fx z 자기상관 0.980)의
train/test 국면 이동, 표본 대비 파라미터 증가.

### 0.3 그래서 주효과 항을 추가

$$g_{i,t} = \alpha_i^\top C_t + (\beta_i + \mathbf{B}_i C_t)^\top \phi_{i,t}$$

이제 $\phi=0$인 날에도 $g=\alpha^\top C \neq 0$이 되어, 컨텍스트가 행동 수준을 직접
움직일 수 있다.

### 0.4 결과 — 3특징에서는 도움, 5특징에서는 무효

- **3특징(2026-07-19):** α 추가 후 처음으로 컨텍스트가 양(+)의 기여. 기관 방향
  0.525→0.542, 개인 0.601→0.608. α 계수는 93~100% 부호 일관성으로 B보다 훨씬 안정.
  부호도 진단과 정합(외국인 $\alpha_{\text{KOSPI}}{=}{+}0.036$, $\alpha_{\text{FX}}{=}{-}0.026$;
  개인은 정확히 거울상).
- **5특징(재계산):** α를 넣어도 **컨텍스트 없는 모델을 넘지 못함**
  (외국인 0.278 < 0.299, 개인 0.261 ≈ 0.259).

→ **해석:** 주효과가 값을 하는 것은 "특징 집합이 그 수준 정보를 못 담고 있을 때"다.
특징이 충분해지면 그 정보가 이미 특징으로 들어와 있어 α는 잉여가 된다.

## 1. Q. 특징이 밋밋하지 않은 날에는, 특징 항과 컨텍스트 항이 더해지면서 중복 효과가 있지 않나?

**A. 개념적으로는 중복이 아니다. 단, 통계적 겹침은 있다.**

세 항은 각각 다른 정보를 담는다.

$$g = \alpha^\top C + \beta^\top\phi + \phi^\top \mathbf{B}C$$

| 항 | 수식 | 담는 정보 |
| --- | --- | --- |
| ① 컨텍스트만 | $\alpha^\top C$ | 특징과 무관하게 국면이 미는 행동 수준 |
| ② 특징만 | $\beta^\top\phi$ | 국면과 무관한 평균 선호 |
| ③ 상호작용 | $\phi^\top \mathbf{B}C$ | 국면에 따라 특징 반응이 달라지는 효과 |

회귀에서 $x_1$, $x_2$, $x_1x_2$를 함께 넣는 **표준적인 주효과 2개 + 상호작용 1개**
구조이며, 세 항은 선형독립이다.

**다만 실질적 우려는 있다.** ①과 ③이 모두 $C$를 쓰므로, $\phi$와 $C$가 상관되면
($\mathrm{corr}(\phi,C)\neq 0$) 두 항이 부분적으로 겹쳐 **계수 분리가 어려워진다**
(다중공선성). 실제로 kospi_return이 momentum(+0.216)·underwater(−0.285)와 상관이
있었고, 이것이 "컨텍스트가 주는 신규 정보가 적다"는 진단의 근거였다.

## 2. Q. 특징이 밋밋한 날에는, 결과가 결국 컨텍스트 항 값 그 자체인가?

**A. 그렇다.**

$\phi = 0$(표준화 후 모든 특징이 평균 수준)이면

$$g = \alpha^\top C + (\beta + \mathbf{B}C)^\top \mathbf{0} = \alpha^\top C$$

②③이 모두 사라지고 ①만 남는다. 그날의 예측은 오롯이 국면 신호로 정해진다 —
"시장이 올랐으니 산다", 혹은 반대로 "환율이 약세니 판다".

## 3. Q. 그렇다면 조건부로 나누면 안 되나? ($\phi=0$일 때 $g=\alpha^\top C$, 그 외에는 $g=(\beta+\mathbf{B}C)^\top\phi$)

**A. 틀린 접근이다. 세 가지 문제가 있다.**

**문제 1 — 이미 그 조건이 자동으로 만족된다.**

원식은 조건문 없이 하나뿐이다.

$$g = \alpha^\top C + (\beta+\mathbf{B}C)^\top\phi$$

여기에 $\phi$ 값을 대입하면 두 경우가 저절로 갈린다.

- $\phi = 0$ 이면 두 번째 항이 0이 되어 → $g = \alpha^\top C$
- $\phi \neq 0$ 이면 두 항이 모두 살아 → $g = \alpha^\top C + (\beta+\mathbf{B}C)^\top\phi$

덧셈 구조가 조건 분기 없이 같은 동작을 이미 한다.

**문제 2 — $\phi\neq0$일 때 국면 효과를 강제로 버리게 된다.**
"그 외에는 $g=(\beta+\mathbf{B}C)^\top\phi$"로 두면 특징이 조금이라도 있는 날에는
$\alpha^\top C$를 0으로 만드는 셈이다. 그러나 모멘텀이 강한 날에도 "시장이 좋아서
더 산다"는 효과는 여전히 존재해야 한다. 정보를 버리는 설계다.

**문제 3 — 불연속이 되어 추정이 깨진다.**

$\phi$가 0으로 가까워질 때 두 번째 가지의 값은 0에 수렴하지만, $\phi$가 정확히 0인
지점에서는 $g$가 갑자기 $\alpha^\top C$로 점프한다.

$$\lim_{\phi \to 0} (\beta+\mathbf{B}C)^\top\phi = 0 \quad \neq \quad \alpha^\top C$$

(a) 미분 불가능하여 경사하강 학습이 불가, (b) $\phi$는 연속값이므로 **정확히 0인 날은
사실상 없어** 그 분기가 발동하지 않음, (c) "$\phi\approx0$"으로 임계값을 두면 그
임계값이 또 하나의 임의 하이퍼파라미터가 된다.

> **핵심:** 선형 덧셈 구조의 장점이 바로 "조건문 없이 두 효과를 부드럽게 합치는 것"이다.
> $\phi$가 작으면 자연히 컨텍스트가, 크면 자연히 특징 효과가 지배하며, 그 사이가
> 연속적으로 이어진다. 조건부 분기는 이 장점을 스스로 버린다.

## 4. Q. 컨텍스트 주효과 항은 결국 또 하나의 특징 아닌가? 특징이 아니라고 할 논리적 근거가 있나?

**A. 주효과 항만 놓고 보면 특징과 수학적으로 구별되지 않는다. 이는 인정해야 한다.**

$C$를 $\phi$에 이어붙여 확장 벡터 $\tilde\phi = [\phi;\,C]$, 확장 가중치
$\tilde\beta = [\beta;\,\alpha]$로 두면

$$\alpha^\top C + \beta^\top \phi = \tilde\beta^\top \tilde\phi$$

즉 "컨텍스트를 특징 목록에 추가한 모델"과 **동치**다.

### 구별을 시도할 수 있는 논거 3가지

**논거 1 — 상호작용 항의 존재로 역할이 다르다 (유일하게 견고)**

전체 식에서 $C$는 두 자리에 등장한다.

$$g = \alpha^\top C + \beta^\top\phi + \phi^\top \mathbf{B}C$$

여기서 첫째 항 $\alpha^\top C$는 특징처럼 작동하지만, 셋째 항 $\phi^\top\mathbf{B}C$는
특징이 할 수 없는 역할을 한다.

$\phi^\top\mathbf{B}C$ 때문에 $C$는 "$g$에 기여하는 변수"이자 동시에 **"$w$를 결정하는
변수"**($w(C)=\beta+\mathbf{B}C$)다. 특징 $\phi$는 다른 특징의 가중치를 바꾸지
못하므로 이 역할을 할 수 없다. 이 비대칭이 유일하게 방어 가능한 구별점이다.

⚠ **단, 우리 실험에서 $\mathbf{B}$가 예측에 기여하지 못했으므로 실증적으로는 약하다.**
"역할은 다르나 그 역할이 값을 하지 못했다"가 정직한 서술이다.

**논거 2 — 행동 $a$와의 곱셈 구조 차이 (성립하지 않음)**

설계 표기에서 특징은 $\phi = a\times$(신호)로 항상 $a$와 곱해지는 반면 $\alpha^\top C$는
$C$에 직접 $a$가 곱해지는 구조라 다르다고 볼 수 있어 보인다. 그러나 최종적으로
$R = g\cdot a$이므로 $\alpha^\top C$도 결국 $a$와 곱해져 **형태가 같아진다.**
→ 이 논거는 버리는 것이 낫다.

**논거 3 — 변수의 출처: 종목 내생 vs 시장 외생 (해석적으로 유효)**

- **특징 $\phi$**: 삼성전자 자체의 상태 — 가격 이력, 해당 주체의 평단, 타 주체 flow.
  **종목·주체 수준**.
- **컨텍스트 $C$**: 종목 밖의 환경 — KOSPI200, 환율. **시장·거시 수준**.

이는 원래 연구 설계(§4)가 명시적으로 나눈 구분이다("상태 변수 = 종목 자체 /
컨텍스트 = 종목 외부 환경"). 실질적 함의는 **다종목 확장**에서 나타난다: $\phi$는
종목마다 다르지만 $C$는 모든 종목이 공유하므로, 구조상 $C$는 "패널 공통 요인"
자리이고 $\phi$는 "개체별 상태" 자리다(고정효과 모형에서 시간더미와 개체변수를
나누는 것과 유사).

⚠ **단, 현재 논문은 단일 종목이라 이 구별이 발현되지 않는다.**

### 종합 평가

| 논거 | 수학적으로 견고? | 우리 논문에서 유효? |
| --- | --- | --- |
| 1. 상호작용($\mathbf{B}C$)으로 역할이 다름 | **예** (유일하게 견고) | 부분적 — B가 예측 기여 못 함 |
| 2. $a$와의 곱셈 구조 차이 | 아니오 (무너짐) | 사용 불가 |
| 3. 변수 출처(종목 vs 시장) | 해석적으로 유효 | 단일 종목이라 미발현 |

### 논문에서 권장하는 서술

억지로 "다르다"고 방어하기보다, 제기될 반박을 논문이 **먼저 인정**하는 편이 강하다.

> "형식적으로 컨텍스트 주효과는 컨텍스트를 특징 벡터에 추가한 것과 동치이다.
> 컨텍스트를 별도 층으로 두는 유일한 근거는 상호작용 항 $\phi^\top\mathbf{B}C$ —
> 즉 컨텍스트가 다른 계수를 조절하는 역할 — 인데, 본 연구에서 그 항은 예측 기여를
> 보이지 않았다. 따라서 우리는 컨텍스트 구조를 서술적 장치로 유지하되, 그 주효과가
> 특징 추가와 구별된다고 주장하지 않는다."

## 5. 전체 요약

| 항목 | 결론 |
| --- | --- |
| 도입 계기 | 상호작용(B)만으로는 컨텍스트가 예측을 개선 못 함 → 진단 결과 **주효과 부재**가 1순위 원인 → α 추가 |
| 이론적 근거 | ① 표현력($\phi=0$일 때도 수준 이동 필요) ② 실증(컨텍스트–flow 직접 상관 ±0.14~0.18) ③ 경제적 해석(위험선호·자금흐름 등 포트폴리오 수준 결정) |
| 중복 여부 | 개념적 중복 아님(주효과 2 + 상호작용 1의 표준 구조). 단 $\phi$–$C$ 상관에 따른 통계적 겹침은 존재 |
| 밋밋한 날 | $g = \alpha^\top C$ 그 자체가 맞음 |
| 조건부 분기 | 틀림 — 덧셈이 이미 그 역할을 하고, 정보를 버리며, 불연속이라 학습·식별이 깨짐 |
| 특징과의 구별 | **주효과만 보면 구별 불가(동치)**. 유일한 구별점은 상호작용 항의 존재이나 실증적으로 약함 → 논문에서는 이를 먼저 인정하는 서술을 권장 |
| 실험 결과 | 3특징에서는 α가 기여, **5특징에서는 컨텍스트 없는 모델을 못 넘음** → 특징이 충분하면 α는 잉여 |
