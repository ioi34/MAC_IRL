## 해석

**초안 이식 수치는 무조건 재계산해야 한다는 것이 이번 검증의 교훈이다.** 조건수 6.86은
계산 코드조차 없는 상태로 원고에 들어가 있었고, 설계행렬이 바뀌었으므로(herd→persist) 값이
달라지는 것이 당연했다. AR(1)도 표본 범위가 달라 두 자리에서 틀렸다.

반면 **유일성 검증 자체는 살릴 가치가 있었다** — 직접 계산해보니 135조합 전부 만계수이고
조건수도 6.94로 안전해, 초안이 넣으려 한 엄밀성이 우리 사양에서도 성립한다. 값만 고치면 된다.

기관 momentum의 `q = 0.0084`가 **저하 q가 아니라 개선 q**라는 점도 확인했다. 일반 `q_value`는
0.998로, 부호를 혼동해 인용하면 정반대 주장이 된다.

## 재현 코드 (조건수 · rank)

```python
import numpy as np, glob, os
d = np.load('data/processed/dataset_continuous_reward3_persist.npz', allow_pickle=False)
F, C = d['features'], d['contexts']
inv = [s for s in d['investors'].astype(str)]
worst = 0.0
for sd in sorted(glob.glob('runs/continuous_reward3_persist/split_*')):
    tr = np.load(os.path.join(sd, 'indices.npz'))['train_indices']
    for k, name in enumerate(inv):
        X, Cc = F[tr, k, :].astype(float), C[tr, :].astype(float)
        Xs = (X - X.mean(0)) / np.where(X.std(0) == 0, 1, X.std(0))
        Cs = (Cc - Cc.mean(0)) / np.where(Cc.std(0) == 0, 1, Cc.std(0))
        W = np.hstack([Xs, np.einsum('ni,nj->nij', Xs, Cs).reshape(len(tr), -1), Cs])
        assert np.linalg.matrix_rank(W) == 11
        worst = max(worst, np.linalg.cond(W))
print('worst cond(W) =', round(worst, 4))
```
